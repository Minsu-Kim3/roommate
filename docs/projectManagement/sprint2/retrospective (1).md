# RoomMate - Sprint 2 Retrospective
Sprint Period: October 13 - November 3, 2026

## What Improved Since Sprint 1
* Registration and login, unfinished in Sprint 1, are complete.
* The backend is now connected to a working website.
* Roommate search was delivered with its own tests, and the suite grew from 16 to 27 test cases.

## Remaining Challenges
* Work was unevenly distributed, and carried-over tasks had to be picked up late in the sprint.
* Integration happened at the very end of the sprint, leaving little time to test the combined application.
* Kanban tracking was still inconsistent. Several Sprint 2 issues were created on November 3, the last day of the sprint, and issue statuses lagged behind the code.

## Key Lessons
* Assigned work needs a check-in date, so a stalled task is noticed while there is still time to reassign it.
* Building on another member's unmerged branch creates rework, as happened when TempUser was renamed to User.

## Action Items for Sprint 3
* Merge features to `main` at least 3 days before the deadline.
* Set a mid-sprint check-in, and reassign any item with no pushed work by then.
* Assign one person to capture the Kanban board at the start, midpoint, and end of the sprint.
* Add tests for FR-06 through FR-10 as each feature is built.

## Conclusion
Sprint 2 turned the Sprint 1 backend into a working application covering FR-01 through FR-05. Sprint 3 will implement roommate requests, notifications, responses, pairing, and the housing administrator view.
